# Artwork

The Finch app icon was created using OpenAI's built-in image-generation tool and iterated around a charcoal tile, ivory finch, and Codex corner badge. The final concept was selected by the project owner. `Assets/AppIcon.png` is the source raster; `make-icon.sh` generates the native ICNS sizes. `Assets/MenuBar.svg` and `FinchBrand.swift` describe the separate single-color menu mark.

The corner badge visually references the blue-violet Codex mark bundled with the Codex desktop client. Codex/OpenAI names and marks belong to their respective owners. This project is independent and the MIT software license does not grant trademark rights or relicense third-party marks.
